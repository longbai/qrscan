# QRScan 扫码

[English](README.md) · [获取 1.0.2 源码](https://github.com/longbai/qrscan/releases/tag/v1.0.2)

QRScan 是一款 iPhone 二维码和条码扫描工具。用相机扫，或识别截图里的码。遇到网址时，可以先查看目标域名、路径和查询参数，再打开链接、复制完整网址或单独复制一个参数值。

## 1.0.2 更新

- **从分享菜单扫截图。** 在「照片」打开截图，点「分享 → 用 QRScan 识别」，即可查看并复制结果。
- **一张图有多个码时，点选要看的码。** 相机支持从结果列表选择，照片支持点缩略图上的编号。列表显示目标域名或码制。
- **按需复制原始参数。** 查询参数支持在解码值和原始值之间切换。查看原始值时，`a+b` 和 `a%2Bb` 会保留各自的写法。
- **扫完继续扫。** 关闭结果后，同一个码还留在取景框时会跳过重复弹窗。相机临时启动失败时，可在扫描页重试。

识别在设备上完成，无需注册。暗处可开手电筒。支持简体中文和英文。

## 构建与测试

需要 iOS 17 或更高版本。用 Xcode 打开 `QRScan.xcodeproj`，运行 `QRScan` scheme。真机可测试相机和「照片」分享菜单，模拟器可测试相册选图。按 **⌘U** 运行单元测试。
